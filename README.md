# Abraham Jaimes — Portfolio

Personal portfolio of Abraham Jaimes, Full Stack Developer. Built with Angular 21.

## Tech Stack

- Angular 21 · Standalone components · Signals · OnPush
- SCSS with custom design system
- i18n in 5 languages (EN, ES, PT, DE, IT)

## Development

```bash
npm install
ng serve        # http://localhost:4200
```

## Build

```bash
ng build --configuration production
```
